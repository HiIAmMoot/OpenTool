The first OpenTool release with a Windows app.

## Download

`OpenTool-v0.1.0-windows-x64.zip` holds `OpenTool.exe`, a window for baking a level's lightmaps, and `OpenTool-cli.exe`, which takes the same commands as `python lightmap.py`. Unzip it and run `OpenTool.exe`. The only thing to install is [Blender 5.2](https://www.blender.org/download/) or newer.

## Lightmapper

- Bakes a structure BSP's lightmaps with Blender Cycles and writes them in the stock format tool writes. The results stay close to tool's.
- Quality presets Draft, Normal and High, or your own values under Advanced. On an RTX 4060 laptop GPU, Blood Gulch takes about 24 seconds at Draft, 70 at Normal and 220 at High.
- Writes the lit level under new tag names, or replaces your tags after asking. Replaced tags are kept in a `backups` folder next to them unless you turn that off (`--no-backups` on the command line).
- Finds Blender on its own and bakes on OptiX, CUDA, HIP or oneAPI, falling back to the CPU.
- Reads and writes tag paths byte for byte, so paths with characters such as `·` or accented letters work.
- On the command line, `-v` shows the progress lines.

## Known limits

- Windows only.
- Tested on one PC with an NVIDIA GPU. AMD and Intel GPUs are untested.
- The app is not signed, so Windows SmartScreen may warn the first time. Choose More info, then Run anyway.
