Scenery lights now bake, CPU-only bakes are about six times faster, and the app warns before a bake that may run out of memory.

## Download

`OpenTool-v0.2.1-windows-x64.zip` holds `OpenTool.exe` and `OpenTool-cli.exe`. Unzip it and run `OpenTool.exe`; the only thing to install is [Blender 5.2](https://www.blender.org/download/) or newer. The zip is TODO MB.

## New

- **Scenery lights.** Static lights attached to scenery, such as torches, now light the level. Dynamic lights never bake. They are real Cycles lights, calibrated against tool's own bakes, and bounce like the sun. Lighting changes on maps with static scenery lights (on the stock maps: b40 and c40). TODO: c40 bake time.
- **Ignore normals.** Shaders flagged "ignore normals" now get their own lighting. Advanced has an "Ignore-normals lighting" choice: Traditional matches tool, Enhanced (the default) lights flagged surfaces from both sides and lets them pass light on.
- **Faster CPU bakes.** The per-vertex pass now runs as compiled code: Rat Race 181 s → 31 s, Putput 394 s → 69 s without a GPU. The first CPU bake compiles it once (about a minute). GPU bakes are unchanged.
- **Memory check.** The app shows how much memory a bake needs and warns if it may not fit; you can still go ahead. If Blender runs out of memory, the bake says so.
- **Device rows** show where the page bake, vertex pass and denoiser will run, and after a bake what ran.
- **Texel density** is a dropdown (1 to 32), and "32-bit lightmaps" moved into Advanced. Both Advanced choices stay as set whatever preset you pick.

## Fixes

- Cut-outs on environment shaders read the bump map's alpha, as the game does: Monaco's fences no longer bake solid.
- Scenery with an origin offset now shadows in the right place.
- Tag references are written with backslashes.
- A finished bake could fail while removing the denoiser's temporary folder ("file in use").

## Known limits

- Windows only; tested on an NVIDIA RTX 4060 laptop GPU and an AMD Radeon 680M.
- On AMD the denoiser runs on the CPU; the app shows this up front.
- The memory figure is an estimate and only warns.
- The app is not signed, so SmartScreen may warn the first time: choose More info, then Run anyway.
