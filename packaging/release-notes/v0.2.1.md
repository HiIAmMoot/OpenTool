Scenery lights now bake, CPU-only bakes are about six times faster, and the app warns before a bake that may run out of memory.

## Download

`OpenTool-v0.2.1-windows-x64.zip` holds `OpenTool.exe` and `OpenTool-cli.exe`. Unzip it and run `OpenTool.exe`. The only thing to install is [Blender 5.2](https://www.blender.org/download/) or newer. The zip is TODO MB.

## New

- Static lights attached to scenery, such as torches, now light the level. Dynamic lights never bake. They bake as Cycles lights calibrated against tool's own bakes, and their light bounces like the sun's. Lighting changes on maps with static scenery lights, which among the stock maps are b40 and c40. TODO: c40 bake time.
- Shaders flagged "ignore normals" get their own lighting. Advanced has an "Ignore-normals lighting" choice. Traditional matches tool. Enhanced, the default, lights flagged surfaces from both sides and lets them pass light on to their neighbours.
- The per-vertex pass runs as compiled code on the CPU. Without a GPU, Rat Race now bakes in 31 s instead of 181 s, and Putput in 69 s instead of 394 s. The first CPU bake compiles it once, which takes about a minute. GPU bakes are unchanged.
- The app shows how much memory a bake needs and warns if it may not fit, but lets you go ahead. If Blender runs out of memory, the bake says so.
- Device rows show where the page bake, the vertex pass and the denoiser will run, and after a bake, what ran.
- Texel density is a dropdown from 1 to 32. "32-bit lightmaps" moved into Advanced. Both Advanced choices stay as you set them whatever preset you pick.

## Fixes

- Cut-outs on environment shaders read the bump map's alpha, as the game does, so Monaco's fences no longer bake solid.
- Scenery with an origin offset now shadows in the right place.
- Tag references are written with backslashes.
- A finished bake could fail while removing the denoiser's temporary folder ("file in use").

## Known limits

- Windows only. Tested on an NVIDIA RTX 4060 laptop GPU and an AMD Radeon 680M.
- On AMD the denoiser runs on the CPU, and the app shows this before the bake.
- The memory figure is an estimate and only warns.
- The app is not signed, so SmartScreen may warn the first time. Choose More info, then Run anyway.
