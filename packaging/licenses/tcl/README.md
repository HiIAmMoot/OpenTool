# Tcl license source

Python 3.11.9's Windows installer includes Tcl 8.6.12 but omits `tcl/tcl8.6/license.terms`. This is the unmodified license text from:

https://github.com/tcltk/tcl/blob/core-8-6-12/license.terms

The collector uses this copy only when the base interpreter's Tcl license is absent and the installed Tcl is 8.6.12. Tk's license still comes from the base interpreter.
